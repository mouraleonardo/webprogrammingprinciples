HTML Form Validation with Practical Examples

This form demonstrates various HTML5 validation attributes and their usage with practical examples.

The required attribute ensures the user cannot leave this field blank.

<input type="text" id="name" name="name" required placeholder="Enter your full name">

Using type="email" validates that the input is a properly formatted email address.

<input type="email" id="email" name="email" required placeholder="Enter a valid email">

The min and max attributes restrict the input to a specific range.

<input type="number" id="age" name="age" required min="18" max="100" placeholder="Enter your age">

The pattern attribute ensures the password meets custom criteria: at least 8 characters, 1 number, and 1 letter.

<input type="password" id="password" name="password" required 
       pattern="(?=.*\d)(?=.*[a-zA-Z]).{8,}" 
       placeholder="Create a strong password">

Make sure the confirmation password matches the original password.

<input type="password" id="confirmPassword" name="confirmPassword" required placeholder="Confirm your password">

Radio buttons allow only one option to be selected. The required attribute ensures a gender is selected.

<input type="radio" id="male" name="gender" value="male" required> Male
<input type="radio" id="female" name="gender" value="female" required> Female
<input type="radio" id="other" name="gender" value="other" required> Other

Checkboxes allow the user to select multiple options. The form requires at least one checkbox to be selected.

<input type="checkbox" id="coding" name="interests" value="coding"> Coding
<input type="checkbox" id="gaming" name="interests" value="gaming"> Gaming
<input type="checkbox" id="reading" name="interests" value="reading"> Reading

The minlength attribute ensures that the user enters at least 5 characters in the text area.

<textarea id="comments" name="comments" required minlength="5" placeholder="Enter your comments"></textarea>

The required attribute ensures the user selects a value from the dropdown list.

<select id="country" name="country" required>
    <option value="usa">United States</option>
    <option value="canada">Canada</option>
    <option value="uk">United Kingdom</option>
</select>
