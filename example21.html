JSON Tutorial

JSON (JavaScript Object Notation) is a lightweight data-interchange format that is easy for humans to read and write, and easy for machines to parse and generate. It is commonly used for API data exchange and web development.

What is JSON?

  • JSON is a text format that represents structured data.
  • It is based on key-value pairs.
  • It is language-independent but works seamlessly with JavaScript.

Basic JSON Syntax

JSON is built on two structures:

  • Objects: A collection of key-value pairs enclosed in curly braces {}.
  • Arrays: An ordered list of values enclosed in square brackets [].

// Example JSON Object
{
    "name": "John Doe",
    "age": 30,
    "isStudent": false,
    "skills": ["JavaScript", "HTML", "CSS"],
    "address": {
        "street": "123 Main St",
        "city": "Springfield"
    }
}

// Example JSON Array
[
    {
        "name": "Alice",
        "age": 25
    },
    {
        "name": "Bob",
        "age": 27
    }
]

Using JSON with JavaScript

JSON can be used with JavaScript to transfer and manipulate data. Here are some common methods:

  • JSON.parse(): Converts a JSON string into a JavaScript object.
  • JSON.stringify(): Converts a JavaScript object into a JSON string.

Practical Examples

Example 1: Parsing JSON


const jsonString = '{"name": "John", "age": 30}'; // JSON string
const jsonObject = JSON.parse(jsonString); // Convert to JavaScript object

console.log(jsonObject.name); // Output: John
console.log(jsonObject.age);  // Output: 30

Example 2: Stringifying a JavaScript Object


const user = {
    name: "Alice",
    age: 25,
    skills: ["JavaScript", "React", "Node.js"]
};

// Convert JavaScript object to JSON string
const jsonString = JSON.stringify(user);

console.log(jsonString);
// Output: {"name":"Alice","age":25,"skills":["JavaScript","React","Node.js"]}
