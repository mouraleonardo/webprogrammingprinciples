Responsive Web Design Tutorial

Introduction

Responsive web design ensures your web page looks good on all devices using only HTML and CSS. It optimizes layout for screens of all sizes, like desktops, tablets, and phones.

This technique resizes, hides, shrinks, enlarges, or moves content to look good on any screen.

Setting The Viewport

The viewport is the user’s visible area of a web page. It varies with device and was introduced in HTML5 for control over dimensions and scaling.

To make the web page responsive, add the following viewport meta tag to the HTML <head>:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

The code sets the page width to the device screen-width and initial zoom level to 1.0, ensuring no horizontal scrolling.

Grid-View

A grid-view layout divides the page into columns, making it easier to place elements responsively. A 12-column grid is common in responsive design.

Example: Define a grid layout using CSS:

/* CSS Example */
* {
  box-sizing: border-box;
}

.menu {
  width: 25%;
  float: left;
}

.main {
  width: 75%;
  float: left;
}

In a 12-column layout, you might assign each column a percentage width:

/* Column Widths */
.col-1 { width: 8.33%; }
.col-2 { width: 16.66%; }
/* And so on up to */
.col-12 { width: 100%; }

HTML Layout Example:

<div class="row">
  <div class="col-3">...</div>  
  <div class="col-9">...</div>  
</div>

Responsive Images

Images should resize to fit various screens. Set width to 100% and height to auto for responsive images:

img {
  max-width: 100%;
  height: auto;
}

The max-width property makes the image scale down if needed but won’t exceed its original size.

Media Queries

Media queries apply CSS rules conditionally based on screen size using the @media rule.

Example: Change background color when the screen width is 600px or smaller:

@media only screen and (max-width: 600px) {
  body {
    background-color: lightblue;
  }
}

Breakpoints

Breakpoints are specific screen widths at which the layout changes. For small screens, set columns to 100% width:

@media only screen and (max-width: 768px) {
  [class*="col-"] {
    width: 100%;
  }
}

Mobile First: Design for mobile screens first. Here’s an example layout that adds columns for larger screens:

/* Mobile Phones */
[class*="col-"] {
  width: 100%;
}

@media only screen and (min-width: 768px) {
  /* Desktop Layout */
  .col-1 { width: 8.33%; }
  .col-2 { width: 16.66%; }
  /* up to col-12 */
}

Orientation and Device Breakpoints

Media queries can also respond to screen orientation:

@media only screen and (orientation: landscape) {
  body {
    background-color: lightblue;
  }
}

Examples of device-specific breakpoints:

/* Extra small devices (600px and down) */
@media only screen and (max-width: 600px) {...}

/* Small devices (600px and up) */
@media only screen and (min-width: 600px) {...}

/* Medium devices (768px and up) */
@media only screen and (min-width: 768px) {...}

Responsive Videos

Set video width to 100% and height to auto for responsive video players:

video {
  max-width: 100%;
  height: auto;
}

This ensures the video scales smoothly across devices without exceeding original dimensions.
