Responsive Web Design - Images

Using the Width Property

Setting the image's width to a percentage and height to auto makes it responsive and scales it up or down as needed.

img {
  width: 100%;
  height: auto;
}

Notice: The image scales to fit the page but may exceed its original size. In many cases, max-width is a better solution.

Using the Max-Width Property

Setting max-width to 100% ensures the image will scale down if necessary but won't be larger than its original size.

img {
  max-width: 100%;
  height: auto;
}

Responsive Background Images

Background images can also be responsive. Here are three methods:

1. Background Size Contain

Using background-size: contain; will scale the background image while keeping its aspect ratio.

.container {
  background-image: url('gt3Racing.jpg');
  background-size: contain;
}

2. Background Size 100% 100%

Using background-size: 100% 100%; stretches the background to fill the container area completely.

.container {
  background-image: url('gt3Racing.jpg');
  background-size: 100% 100%;
}

3. Background Size Cover

Using background-size: cover; scales the background to cover the entire area, while preserving the image's aspect ratio.

.container {
  background-image: url('gt3Racing.jpg');
  background-size: cover;
}

Different Images for Different Devices

Load different images for different screen sizes using media queries:

/* For width smaller than 400px */
body {
  background-image: url('gt3Racing.jpg');
}

/* For width 400px and larger */
@media only screen and (min-width: 400px) {
  body {
    background-image: url('gt3Racing.jpg');
  }
}

Using min-device-width instead of min-width keeps the image from changing when resizing the browser window.

The HTML <picture> Element

The <picture> element allows specifying different images for different screen sizes, enhancing responsive design by loading optimal images for each screen size.

<picture>
  <source srcset="gt3Racing.jpg" media="(max-width: 400px)">
  <source srcset="gt3Racing.jpg">
  <img src="gt3Racing.jpg" alt="Flowers">
</picture>
