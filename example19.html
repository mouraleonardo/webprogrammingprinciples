HTML Forms and Input Controls

HTML Forms

HTML forms are used to collect user input. Forms contain various input elements like text fields, checkboxes, and buttons.

<form action="/submit" method="post">
  <label for="name">Name:</label>
  <input type="text" id="name" name="name">

  <label for="email">Email:</label>
  <input type="email" id="email" name="email">

  <button type="submit">Submit</button>
</form>

HTML Input Types

HTML input elements can have various types, such as text, password, number, and more, each with different behaviors and features.

<form>
  <input type="text" placeholder="Text">
  <input type="password" placeholder="Password">
  <input type="number" placeholder="Number">
</form>

HTML Input Attributes

Various attributes can customize input elements, such as required, maxlength, and min/max to define value constraints.

<form>
  <input type="text" required placeholder="Required Input">
  <input type="number" min="1" max="10" placeholder="1 to 10">
</form>

Special Input Attributes

The readonly, disabled, and placeholder attributes provide additional ways to modify input behavior.

<form>
  <input type="text" placeholder="Editable Field">
  <input type="text" readonly value="Read-Only Field">
  <input type="text" disabled value="Disabled Field">
</form>
