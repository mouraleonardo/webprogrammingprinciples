CSS Tutorial

CSS Syntax

CSS is written in a simple syntax consisting of selectors and declaration blocks. Each declaration block contains properties and values.

selector {
    property: value;
}

Example:

h1 {
    color: blue;
}

CSS Selectors

Selectors are patterns used to select the elements you want to style. Types of selectors include:

  • Element Selector: Selects all elements of a given type.
  • Class Selector: Selects elements with a specific class attribute (e.g., .className).
  • ID Selector: Selects an element with a specific ID (e.g., #idName).

Example:

p {
    font-size: 16px;
}
.className {
    background-color: yellow;
}
#idName {
    margin: 20px;
}

CSS How To

To apply CSS styles, you can use inline styles, internal styles, or external styles:

  • Inline Styles: Apply CSS directly on an element using the style attribute.
  • Internal Styles: Include CSS in the <head> of your HTML document using a <style> tag.
  • External Styles: Link to a separate CSS file using the <link> tag.

CSS Comments

Comments in CSS are used to leave notes and are not rendered in the browser. They start with /* and end with */.

/* This is a comment */
p {
    color: red; /* This sets the text color */
}

CSS Colors

CSS allows you to use various formats to define colors:

  • Named Colors: e.g., red, blue
  • Hexadecimal: e.g., #ff0000 for red
  • RGB: e.g., rgb(255, 0, 0) for red

Example:

body {
    background-color: #f0f0f0;
}
h1 {
    color: rgb(0, 128, 0);
}

CSS Backgrounds

CSS backgrounds can be applied to elements using the background-color property or by using images.

div {
    background-color: lightblue;
    background-image: url('image.jpg');
    background-size: cover;
}

CSS Borders

CSS borders can be applied to elements using the border property.

div {
    border: 2px solid black;
    border-radius: 5px; /* Rounded corners */
}

CSS Margins

Margins create space around elements. You can set margins for all sides or individually.

div {
    margin: 20px; /* All sides */
    margin-top: 10px; /* Top */
}

CSS Padding

Padding creates space inside elements. It is the space between the content and the border.

div {
    padding: 15px; /* All sides */
    padding-left: 10px; /* Left */
}

CSS Height/Width

You can set the height and width of elements using the height and width properties.

div {
    width: 300px;
    height: 150px;
}

CSS Box Model

The CSS box model consists of margins, borders, padding, and the content area.

div {
    width: 300px;
    padding: 20px;
    border: 5px solid black;
    margin: 10px;
}

CSS Outline

The outline property is similar to borders but does not take up space in the box model.

div {
    outline: 2px dashed red;
}

CSS Text

You can style text using properties like color, text-align, and line-height.

p {
    color: navy;
    text-align: center;
    line-height: 1.5;
}

CSS Fonts

You can set font properties such as font-family, font-size, and font-weight.

h1 {
    font-family: 'Arial', sans-serif;
    font-size: 24px;
    font-weight: bold;
}

CSS Icons

CSS can be used to style icon fonts like Font Awesome or use SVG images.

.icon {
    font-family: 'Font Awesome 5 Free';
    font-weight: 900;
}

CSS Links

You can style links using the a selector and pseudo-classes like :hover.

a {
    color: blue;
    text-decoration: none;
}
a:hover {
    color: red;
}

CSS Lists

Lists can be styled using list-style-type and padding.

ul {
    list-style-type: square;
    padding-left: 20px;
}

CSS Tables

Tables can be styled using properties like border, border-collapse, and padding.

table {
    border-collapse: collapse;
    width: 100%;
}
td {
    border: 1px solid black;
    padding: 8px;
}

CSS Display

The display property specifies the display behavior of an element. Common values include block, inline, and flex.

div {
    display: block;
}
span {
    display: inline;
}
.container {
    display: flex;
}

CSS Max-width

The max-width property sets the maximum width of an element. It prevents the width from exceeding a specified value.

div {
    max-width: 600px;
}

CSS Position

The position property specifies how an element is positioned in the document. Common values include static, relative, absolute, and fixed.

.relative {
    position: relative;
    top: 10px;
    left: 20px;
}
.absolute {
    position: absolute;
    top: 0;
    left: 0;
}

CSS Z-index

The z-index property specifies the stack order of elements. Higher values are displayed in front of lower values.

div {
    position: absolute;
    z-index: 10;
}

CSS Overflow

The overflow property controls what happens to content that is too large for its container. Options include visible, hidden, scroll, and auto.

div {
    overflow: hidden;
}

CSS Float

The float property is used for positioning elements to the left or right, allowing text to wrap around them.

img {
    float: left;
    margin-right: 10px;
}

CSS Inline-block

The display: inline-block property allows elements to sit next to each other while still allowing width and height to be set.

div {
    display: inline-block;
    width: 100px;
    height: 100px;
    margin: 10px;
}

CSS Align

Text alignment can be achieved using the text-align property, and flexbox can be used to align items in a container.

.container {
    display: flex;
    justify-content: center; /* Aligns horizontally */
    align-items: center; /* Aligns vertically */
}

CSS Combinators

Combinators describe the relationship between selectors:

  • Descendant Selector: div p selects all p elements inside div elements.
  • Child Selector: div > p selects all p elements that are direct children of div.
  • Adjacent Sibling Selector: h1 + p selects the first p element after any h1.
  • General Sibling Selector: h1 ~ p selects all p elements after any h1.

CSS Pseudo-classes

Pseudo-classes are used to define the special state of an element. Examples include:

  • :hover
  • :focus
  • :nth-child()
a:hover {
    color: red;
}
li:nth-child(2) {
    background-color: yellow;
}

CSS Pseudo-elements

Pseudo-elements are used to style specific parts of an element. Examples include:

  • ::before
  • ::after
  • ::first-line
p::first-line {
    font-weight: bold;
}
p::before {
    content: "Note: ";
    color: red;
}

CSS Opacity

The opacity property sets the transparency level of an element, where 0 is fully transparent and 1 is fully opaque.

div {
    opacity: 0.5; /* 50% transparent */
}

CSS Navigation Bar

A navigation bar can be styled using flexbox for layout and hover effects for links.

nav {
    display: flex;
    background-color: #333;
}
nav a {
    color: white;
    padding: 14px 20px;
    text-decoration: none;
}
nav a:hover {
    background-color: #575757;
}

CSS Dropdowns

Dropdown menus can be created using nested lists and CSS for styling.

ul {
    position: relative;
}
ul li:hover ul {
    display: block;
}
ul ul {
    display: none;
    position: absolute;
}

CSS Image Gallery

Image galleries can be styled using CSS grid or flexbox for a responsive layout.

.gallery {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
    gap: 10px;
}

CSS Image Sprites

Image sprites combine multiple images into one for better performance.

.sprite {
    background-image: url('sprites.png');
    background-position: -10px -10px; /* Adjust for specific icon */
    width: 50px;
    height: 50px;
}

CSS Attribute Selectors

Attribute selectors allow you to style elements based on their attributes.

input[type="text"] {
    border: 1px solid #ccc;
}
a[target="_blank"] {
    color: blue;
}

CSS Forms

Forms can be styled using various CSS properties for inputs, buttons, and labels.

input {
    padding: 10px;
    border: 1px solid #ccc;
}
button {
    background-color: blue;
    color: white;
}

CSS Counters

CSS counters can be used to create numbered lists automatically.

ol {
    counter-reset: item;
}
ol li {
    counter-increment: item;
}
ol li::before {
    content: counter(item) ". ";
}

CSS Website Layout

Layouts can be created using CSS grid or flexbox for responsive design.

.container {
    display: grid;
    grid-template-columns: 1fr 3fr;
}
.sidebar {
    grid-column: 1;
}
.content {
    grid-column: 2;
}

CSS Units

CSS supports various units such as pixels (px), percentages (%), ems (em), and rems (rem).

div {
    width: 50%; /* 50% of the parent element */
    padding: 1em; /* 1em based on the font size */
}

CSS Specificity

Specificity determines which CSS rule is applied when multiple rules could apply to the same element.

  • Inline styles have the highest specificity.
  • ID selectors are more specific than class selectors.
  • Class selectors are more specific than element selectors.

CSS !important

The !important declaration can be added to a CSS rule to give it higher priority over other rules.

p {
    color: blue !important; /* This will override other color rules */
}

CSS Math Functions

CSS includes math functions like calc() for calculations.

div {
    width: calc(100% - 50px); /* 100% minus 50 pixels */
}
